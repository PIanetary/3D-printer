# 3D-printer
I'm trying to make a DIY 3D printer.
I've been thinking about making a 3D printer for a while now and I finally started. I started with CAD for now and in my opinion I've finished however I'm not completely done, some of the mates weren't working out so I kinda just quit for that. Also I was using some step files to map out where the motors etc would go but they have a lot of parts which made the software laggy which is another reason I was tired of doing it and wasting time. I also didn't include the electronics like the arduino, mofset, psu etc. because I know where they will go on the printer. The CAD was mainly for the purpose of mapping out where everything will go, although I will probably make some adjustments during the building phase of this project, this was more like a rough draft.  <img width="1702" height="948" alt="image" src="https://github.com/user-attachments/assets/19d57e78-7c70-44d2-aaf7-075f1b21eb63" />
