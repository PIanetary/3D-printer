# 3D-printer
I'm trying to make a DIY 3D printer.
I've been thinking about making a 3D printer for a while now and I finally started. I started with CAD for now and in my opinion I've finished however I'm not completely done, some of the mates weren't working out so I kinda just quit for that. Also I was using some step files to map out where the motors etc would go but they have a lot of parts which made the software laggy which is another reason I was tired of doing it and wasting time. I also didn't include the electronics like the arduino, mofset, psu etc. because I know where they will go on the printer.
